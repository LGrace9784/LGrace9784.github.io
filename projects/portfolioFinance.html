Financial Analytics/Portfolio Tracker

Description

Developed a full-stack portfolio tracking application designed to help users monitor investments, analyze portfolio performance, and manage financial assets in one centralized platform. The application provides real-time portfolio insights, tracks gains and losses, and delivers a clean, user-friendly interface for managing investment data. The project focused on building scalable backend services, efficient database management, and responsive frontend functionality while strengthening experience with API development and full-stack software engineering practices.

  • Java Rest API
  • PostgreSQL
